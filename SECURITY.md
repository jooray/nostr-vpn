# Security reports

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/mmalmi/nostr-vpn/security/advisories/new).
Reports are shared privately with the repository maintainers.

Include the affected version and platform, the expected and observed behavior,
and enough detail to reproduce the problem. Remove private keys, credentials,
personal information, and unrelated network details from logs and examples.

Please keep vulnerability details out of public issues until a fix or disclosure
has been coordinated. Use [GitHub issues](https://github.com/mmalmi/nostr-vpn/issues)
for ordinary bug reports and feature requests.
